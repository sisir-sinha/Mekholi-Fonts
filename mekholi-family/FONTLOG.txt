2026-11-06 — Version 1.0, Regular Prototype 1
- Created a Kalpurush 0.258 derivative with 3% horizontal expansion.
- Updated matching spacing and mark positioning; revised vertical metrics.
- Removed invalidated hints and legacy device metrics.
- Renamed the family Mekholi and added project designer/developer credits.
- Generated TTF, WOFF, WOFF2; other family styles remain planned.

2026-11-06 — OFL metadata/package revision 2; outlines unchanged
- Copyright holders for Mekholi modifications confirmed as Surajit Singha
  Sisir and Ningshing Che. Mekholi declared a Reserved Font Name.
- Preserved the upstream copyright and Reserved Font Name Kalpurush.
- Embedded complete bundled OFL 1.1 text in name ID 13.
- Set name ID 14 to https://openfontlicense.org/ and fsType to 0.
- Removed contradictory historical license wording from active Mekholi
  copyright metadata; unmodified source font and README retain it as evidence.
- Included official OFL-FAQ.txt and added licensing guidance to project files.
- Rebuilt all formats and embedded preview fonts; reran validation.

2026-11-06 — Version 1.0, Experimental Family 1
- Expanded to 18 static styles: weights 100–900, upright and 12° slanted italic.
- Mechanical weight offsets through FreeType with Skia PathOps overlap cleanup.
- Preserved original shaping tables and glyph order; shear-adjusted GPOS anchors
  and offsets for slanted styles; recalculated sidebearings, retained advances.
- Added consistent family vertical metrics and style-linking metadata.
- Embedded full OFL 1.1 and both original and new copyright/RFN notices.
- Generated 54 font files (TTF/WOFF/WOFF2), CSS and visual specimens.
- 73,854 structural/synthetic shaping cases pass implemented tests.
- Experimental only: not true drawn italics, optically refined weight masters,
  newly original letterforms or native-language/production certification.
