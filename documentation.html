1. About Mekholi

Mekholi, displayed in Bengali as মেখলি, is a serif font project intended for Bishnupriya Manipuri in the Bengali/Assamese script. Its internal font-family name remains Mekholi; the Bengali display name does not change the installable family name.

  • Designer: Surajit Singha Sisir
  • Developer: Ningshing Che
  • Version: 1.0 / Experimental Family 1
  • Targets: web and print media
  • Formats: static TTF, WOFF and WOFF2
Not a finished original typeface. This is a Kalpurush-derived experiment. The first Regular changes width and engineering, not its underlying design vocabulary. Language-specific validation has not been completed.

4. Install on desktop

Windows

  1. Extract the ZIP. Select the desired files in fonts/ttf/.
  2. Right-click and choose Install, or open them in the Windows font installer.
  3. Restart your design or document application and choose Mekholi.

macOS

Open the TTF files in Font Book and install them. Resolve duplicate or old Mekholi test builds before using a replacement.

Linux

Copy the TTF files to ~/.local/share/fonts/Mekholi/ and refresh the font cache:

mkdir -p ~/.local/share/fonts/Mekholi
# Copy the desired TTF files to that directory, then:
fc-cache -f

Modern apps should group styles using typographic names. Older apps may list weight-specific families such as Mekholi Thin, with Regular/Italic links. Do not install both the earlier standalone prototype and the current family Regular at once.

5. Self-host on the web

Copy the complete fonts/web/ directory, preserving the relative paths inside mekholi.css. Prefer WOFF2; WOFF is provided as an alternative. TTF is primarily the desktop format.

<link rel="stylesheet" href="fonts/web/mekholi.css">
<p class="mekholi" lang="bpy">মেখলি</p>
.mekholi {
  font-family: 'Mekholi', serif;
  font-weight: 400;
  font-style: normal;
  font-synthesis: none;
  line-height: 1.75;
}
h1.mekholi { font-weight: 700; }
em.mekholi { font-style: italic; }

Use lang="bpy" for actual Bishnupriya Manipuri content and appropriate language tags for other content. Declaring a language is not proof that the font covers its entire orthography.

Load only what you need

The stylesheet declares 18 faces, but browsers normally fetch only those used. For a site using only Regular and Bold, you can retain just those declarations. Keep the OFL and notices with redistributed font assets.

@font-face {
  font-family: 'Mekholi';
  src: url('./Mekholi-Regular.woff2') format('woff2'),
       url('./Mekholi-Regular.woff') format('woff');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

Serve fonts with correct MIME types (font/woff2, font/woff, font/ttf). If hosting on another origin, configure CORS. Avoid absolute domain-root paths on GitHub project Pages: relative paths keep the /Mekholi-Fonts/ prefix intact.

6. Print & document workflow

Use the TTF files in a Unicode-aware application. Select explicit shipped weights instead of synthetic bold or slant. Before publication:

  1. Check every language-specific letter, conjunct and mark using native-language text.
  2. Review small text at the actual printed size. Thin details can disappear; heavy counters can close.
  3. Check line spacing and clipping, especially below-base vowel signs and stacked marks.
  4. Export a PDF with the chosen fonts embedded; inspect the PDF’s font list and glyph output.
  5. Make a physical proof on the intended paper and printing process.

The supplied PDF specimen is a raster proof sheet, not an embedded-font PDF or a prepress/PDF-X certification. No production press test has been completed.

7. Script & character coverage

Every style retains 586 glyphs and 210 directly mapped Unicode code points from the upstream coverage, including basic Latin letters, ASCII and Bengali digits, and much of the Bengali/Assamese script. Unicode coverage is not the same as language completeness.

Known missing assigned Bengali-block code points include U+0980, U+09FB, U+09FC, U+09FD and U+09FE. No new language-specific glyphs or conjunct designs were added.

Download the mapped code-point list (JSON). The playground checks typed characters against this list. It treats whitespace and ZWJ/ZWNJ separately. The checker is deliberately a direct-cmap test: normalization, variation sequences and complex shaping may require further interpretation.

Provide a verified Bishnupriya Manipuri alphabet and corpus, including any required use of ৰ/ৱ, punctuation, numerals and uncommon conjuncts, before claiming complete language support.

8. Bengali shaping & spacing

The family inherits Kalpurush’s beng and bng2 OpenType shaping support, including GSUB substitutions and GPOS mark positioning. The initial 3% horizontal expansion was applied consistently to outlines, advances and horizontal positioning.

Mechanical weights retain the initial advances, with recalculated outline sidebearings. Italic-labelled fonts shear positioning anchors and placement offsets to follow the slanted outlines. Their spacing and mark relationships have not received a full optical redesign.

Current shared metrics: hhea/typo ascent 1100, descent -650, line gap 0; Windows ascent 1300, descent 700; units per em 1000. A web line-height of 1.75 is a starting point, not a requirement for every layout.

Do not insert spaces inside conjuncts or strip virama/joiners to “fix” rendering. Use a modern shaping engine. Letter-spacing can disrupt the intended rhythm of connected script; use it sparingly.

9. Playground guide

Open the live sandbox to paste text, select a weight and slant, change size/leading/tracking/alignment and choose foreground/background colors.

  • Presets: the supplied name, script repertoire, marks/conjuncts, digits or Latin—not invented native prose.
  • Coverage notice: lists unmapped code points that may display in a fallback font.
  • Copy CSS: copies the selected settings; first load the web-font CSS on your own site.
  • Share: encodes up to 1,500 characters in the URL fragment. The app does not upload your sample.
  • Export PNG: generates a 2× raster proof locally after loading the selected font. Wrapping can differ from the DOM preview; long unbreakable sequences can overflow.
  • Reset: restores defaults and clears the shared URL fragment.

No server-side text storage, analytics or external font CDN is used by the site. GitHub Pages still receives normal asset/page requests. Anyone you share a sample link with can read its text; do not put confidential text in shared links. Rendering and clipboard behavior depend on your browser and security context.

10. Validation & known limitations

Read the full machine-readable report. The current font build passed 4,103 representative/synthetic strings per style, 73,854 cases total.

  • TTF table and full-file checksums pass; outlines load with no newly empty glyphs.
  • Coverage and glyph selection/cluster mapping match upstream.
  • No missing output glyphs or overflow beyond the chosen Windows vertical metrics occurred in the tested corpus.
  • License, weight, style and embedding metadata were checked; WOFF/WOFF2 reopen with matching cmap and glyph order.
“Pass” is limited to those checks. It does not certify every conjunct, collision, contour, stacked mark, hinting behavior, optical weight, browser, operating system or printing workflow. Grid-fitting instructions were removed, not regenerated. Native-language review is still required.

11. Rebuild & contribute

The bundle includes the original upstream input and Python build tools. On Linux, install Python 3.11+ and the FreeType shared library, then run from the family directory:

cd mekholi-family
pip install -r source/requirements.txt
python source/build_family.py
python source/validate_family.py

The build uses fontTools, FreeType contour offsets, Skia PathOps cleanup, Brotli and HarfBuzz validation. It produces static fonts; the input is a binary font, not an original multi-master design source. The exact dependency versions are pinned in source/requirements.txt.

To regenerate the documentation pages and ZIP from the repository root:

python tools/build_site.py
python tools/check_site.py

Report issues with the exact text/code points, style, size, application/version, operating system and a screenshot or PDF. Suggested next work: a verified language corpus, distinct letterform redraws, optical weight masters, real italic designs, refined spacing, hinting and platform/press tests.

12. Troubleshooting

Boxes or unexpected letterforms

Check the playground’s unmapped-character list and use a Unicode-aware shaping application. A browser may substitute another font silently. The font does not support every script or symbol.

Wrong weight or italic

Ensure the requested file is present, the CSS has matching weight/style declarations, and the browser network panel shows no 404/CORS errors. Disable synthetic styles when comparing actual files.

Old design still appears

Remove duplicate prototype installs, restart the app, refresh font caches where appropriate, and hard-refresh the website. Desktop font caches and browser caches are separate.

Marks clip or lines overlap

Increase line-height, remove fixed-height clipping/overflow, and test a current text engine. Record the exact code-point sequence for a bug report.

Playground does not load from a downloaded HTML file

This site uses local font and JSON requests. Serve the repository through HTTP, for example python -m http.server 8000, then open it in a browser. The separate bundled specimen HTML has embedded fonts and is designed for standalone viewing.
