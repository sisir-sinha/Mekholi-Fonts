## What this means
Use and embed the fonts in web and print work, including commercial documents. Redistribution of the font requires preserving notices and the OFL. Font files cannot be sold by themselves. Modified versions must respect the reserved names or obtain permission. Documents made using the font are not required to use the OFL. The font remains a Kalpurush-derived prototype, not a new original drawing or a certified production release.
